# Nova Hue — Capture Your Prism

## Project Overview
Nova Hue is a website designed for cosmetologists, stylists, clients, and salon managers.

The website includes three pages:
- Home (index.html)
- Features (features.html)
- About / Contact (about.html)

## Milestone 3 — Accessibility and Visual Design

### Accessibility Improvements
1. Added skip links to help keyboard users reach the main content.
2. Used semantic HTML elements to organize the website.
3. Added visible keyboard focus indicators.
4. Added accessible navigation labels and active-page indicators.
5. Added labels to contact form fields.
6. Added inline form validation and error messages.
7. Added responsive layouts for mobile devices.

### WCAG AA Color Contrast
Nova Hue uses purple, lavender, and white colors.

Color contrast will be checked using WAVE and the WebAIM Contrast Checker.

Final contrast results: Pending testing.

### Gestalt Design Principles

**Similarity:** Feature cards use consistent colors, borders, fonts, and spacing to show that they belong together.

**Proximity:** Related information is grouped together, including navigation links, feature descriptions, and contact form fields.

### Accessible Contact Form
The About / Contact page contains four required fields:
1. Full Name
2. Email Address
3. Reason for Contact
4. Your Message

The form includes labels, a fieldset and legend, inline error messages, and validation feedback.

This is a demonstration form and does not send real messages.
